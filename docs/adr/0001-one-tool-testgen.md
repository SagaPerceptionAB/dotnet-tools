# 0001. Ett verktyg: testgen

## Status
Antagen 2026-11-08.

## Beslut
Allt heter `testgen`. Kommandot `testgen ui` byter namn till `testgen web`.

## Varför
Flera namn på samma sak ger flera ingångar att lära sig och underhålla.

## Följder
- Kod, paket, dokumentation och kommandon byter namn direkt (se ADR 0003).
- systemmap får samma namnstandard när den skrivs om.
